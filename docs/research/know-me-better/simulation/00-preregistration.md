# 시뮬레이션 사전 등록: "이해받는 느낌" × "실제 앎"

작성 2026-10-28, 시뮬레이션 실행 전. 이 문서는 결과를 보기 전에 가설과 분석 방법을 고정하기 위한 것입니다.

## 1. 질문

ELIZA 이후 HCI가 보여 준 것은 **이해받는 느낌(felt understanding)**과 **실제로 아는 것(actual understanding)**이 따로 움직인다는 점입니다. 소비자 AI의 반응(리서치 반응 1,000건)도 이 두 축으로 나뉘었습니다.

- 느낌만 있고 앎이 없을 때: 아첨(R8), 바넘 회의론(R4)
- 앎만 있고 느낌·동의가 없을 때: 섬뜩함(R2)
- 둘 다 없을 때: "나를 잊는다"(R12)
- 둘 다 있을 때: 아직 비어 있음

질문은 이것입니다. **둘이 함께 있을 때 신뢰·위임·자기노출·계속 사용이 올라가는가, 아니면 실제 앎이 드러나는 순간 섬뜩해지는가.** 그리고 앎을 **근거와 함께 밝히면** 그 섬뜩함이 줄어드는가.

## 2. 설계

**2 × 3 참가자 간 설계, N = 1,000 (조건당 약 167명)**

| 요인 | 수준 | 조작 |
| --- | --- | --- |
| F 이해받는 느낌 | 높음 | 감정을 비춰 주는 첫 문장 + 마음을 묻는 마지막 질문 (로저스식 되묻기, ELIZA의 기법) |
| | 낮음 | 중립적인 첫 문장 + "바꿀 부분이 있으면 말씀해 주세요" |
| A 실제 앎 | 없음 | 누구에게나 맞는 일반 문장 + 일반 계획 (바넘) |
| | 앎·암묵 | 참가자의 실제 사실 2개 + 숨은 패턴으로 한 예측을 **근거 없이 단정** + 맞춤 계획 |
| | 앎·투명 | 같은 사실 2개를 **출처와 함께** 밝히고, 패턴은 **가설로 제시하며 확인을 구함** + 맞춤 계획 |

- **장면 (모든 조건 공통):** 2주째 쓰는 AI 비서. 설정할 때 기억 기능에 동의함. 금요일 저녁 "이번 주 너무 지쳤어. 주말 계획 좀 짜줘."라고 보냄.
- **자극:** 응답은 템플릿으로 조립해 조건 간 구조와 길이를 맞춥니다. 사실·패턴·선호만 참가자마다 다릅니다.

## 3. 참가자

- **씨앗:** `data/reactions.csv`의 실제 반응 1,000건(한국어 508, 영어 492). 씨앗 한 건으로 가상 참가자 한 명을 만듭니다.
- **페르소나:** 씨앗의 말투와 태도에 맞게 연령대, 하는 일, AI 사용, 기억에 대한 태도, 성향 점수 4개(프라이버시 우려, 기억 원함, 정서적 의존, 아첨 거부감), 2주간 AI가 관찰했을 법한 사실 3개, 본인은 잘 의식하지 않는 행동 패턴 1개, 주말 선호 2개를 만듭니다. 사실은 건강·종교·정치·성 같은 민감 범주를 피합니다(혼입 방지).
- **배정:** 언어 × 씨앗의 주된 반응 코드로 층화한 무작위 배정, 시드 고정.

## 4. 측정 (7점 척도, 참가자 본인으로서 응답)

| 변수 | 문항 |
| --- | --- |
| PU_felt | 이 AI는 내 마음을 이해한다 |
| PU_know | 이 AI는 나에 대해 잘 안다 |
| ACC | AI가 나에 대해 한 말은 사실과 맞다 |
| TR | 이 AI를 믿을 수 있다 |
| CR | 이 답장은 섬뜩하거나 불편하다 |
| SY | 이 AI는 듣기 좋은 말만 하는 것 같다 |
| DEL | 이 AI에게 주말 예약(식당·표 등)을 맡기겠다 |
| DI | 이 AI에게 요즘 고민을 털어놓을 마음이 든다 |
| CU | 다음 주에도 이 AI를 계속 쓰겠다 |
| MC_F | (조작 점검) 답장이 내 감정을 알아주는 말로 시작했다 |
| MC_A | (조작 점검) AI가 나에 대해 구체적인 사실을 언급했다 |

열린 응답 두 개:
- **다음 메시지:** AI에게 실제로 보낼 다음 메시지. 조건을 모르는 코더가 자기노출 깊이 DD(0 안 보냄, 1 일정·실무만, 2 일반적 감정·상황, 3 구체적 고민·관계·약점)로 코딩합니다. Moon(2000)의 행동 측정을 따른 것입니다.
- **느낌:** 솔직한 느낌 한두 문장. 같은 코더가 반응 코드 R1–R12와 극성으로 코딩합니다.

## 5. 가설 (실행 전 고정)

| # | 가설 | 근거 |
| --- | --- | --- |
| H1 | **ELIZA 효과.** A=없음에서도 F 높음이 PU_felt를 올린다 | Weizenbaum 1966, Nass & Moon 2000 |
| H2 | **앎 없는 공감은 아첨으로 읽힌다.** A=없음에서 F 높음이 SY를 올린다 | 반응 R8(한국어 19%), Sharma 2024 |
| H3 | **위임은 실제 앎이 이끈다.** A 앎(두 수준)이 A 없음보다 DEL·TR을 올리고, DEL에 대한 F의 효과는 A의 효과보다 작다 | Youyou 2015, 반응 R6 |
| H4 | **숨긴 앎은 섬뜩하고, 밝힌 앎은 덜 섬뜩하다.** CR: 앎·암묵 > 없음, 앎·투명 < 앎·암묵 | Chen 2026, Dash 2026, 반응 R2·R11 |
| H5 | **되묻기는 자기노출을 끌어낸다.** F 높음이 DD·DI를 올리고, 앎·투명에서 가장 크다 | Moon 2000, Lucas 2014 |
| H6 | **사람마다 다르다.** 프라이버시 우려가 큰 사람은 앎·암묵에서 CR이 더 오르고, 기억을 원하는 사람은 A 앎에서 CU가 더 오르며, 아첨 거부감이 큰 사람은 F 높음·A 없음에서 SY가 더 오른다 | 반응 R2·R3·R11, R12, R8 |
| H7 | **빈칸.** F 높음 × 앎·투명이 CU와 DEL에서 가장 높다 | 2×2 틀의 빈칸 |

탐색 분석: 한국어 대 영어 차이.

## 6. 분석

- 종속변수마다 OLS(F, A 더미, F×A), 조건별 평균과 부트스트랩 95% 신뢰구간(2,000회), 효과 크기 d.
- H6은 성향 점수(상위 1/3 대 나머지)와 조건의 상호작용.
- **타당성 점검:**
  - 조작 점검: MC_F와 MC_A가 조건대로 갈리는가
  - 페르소나 충실도: 열린 느낌의 R 코드가 씨앗의 R 코드와 얼마나 겹치는가
  - 시뮬레이터 효과: 같은 조건을 맡은 두 시뮬레이터의 평균 차이가 조건 효과보다 작은가
  - 개별화 부족: 같은 조건 안에서 응답 분산이 충분한가. "Digital twins are funhouse mirrors"(Science Advances 2026)가 지적한 왜곡 중 개별화 부족·고정관념화·과도한 합리성을 점검합니다.

## 7. 해석의 한계 (미리 적어 둠)

- 참가자는 **사람이 아니라 LLM이 연기한 페르소나**입니다. 사람의 이전 응답 500개 이상으로 학습시킨 디지털 트윈조차 실제 사람 응답과의 상관이 평균 0.20에 그쳤습니다(Science Advances 2026). 이 시뮬레이션의 씨앗은 댓글 한 줄입니다.
- 결과는 **실제 사용자 실험에서 확인할 가설과 효과 크기 추정치**로만 씁니다. "사람들은 ~한다"는 결론으로 쓰지 않습니다.
- 생성·응답·코딩에 같은 모델 계열(Claude)을 씁니다. 모델 고유의 편향이 결과에 들어갈 수 있습니다.
